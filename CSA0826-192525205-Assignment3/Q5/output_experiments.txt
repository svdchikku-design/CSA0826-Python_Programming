   sys.getsizeof(list comprehension result) =  8,448,728 bytes (just the pointers; the 950,120 floats are shared with the input)
   sys.getsizeof(generator expression)      =        208 bytes (a generator stores its position, not its values - whatever the input size)
   n =    10,000: peak extra memory  sum([list comp]) =      83.2 KB | sum(generator) =   0.41 KB
