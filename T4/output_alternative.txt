version                     errors  open files before  open files after  still open (leaked)
original (no with/finally)     100                  4               104                  100
manual try/finally             100                104               104                    0
with statement                 100                104               104                    0

Time for 20,000 successful calls of 5 lines (the complexity is the same, O(lines) per call):
  manual try/finally    0.091 s
  with statement        0.093 s

Space: both hold exactly one file object and one buffer at a time: O(1) extra. The difference is correctness, not Big-O:
one error in the original leaks 1 open file; with 'with' or a correct try/finally 0 files remain open.
If the programmer forgets close() inside finally, or opens the second file before the try, one file can still leak per error.
