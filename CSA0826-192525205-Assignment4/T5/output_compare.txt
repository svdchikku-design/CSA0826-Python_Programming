=== 1. The three import forms (package attendance/) ===
import attendance.stats       -> name bound: 'attendance' -> True | 'stats' bound directly: False | call: attendance.stats.percentage(3,1) = 75.0
from attendance import stats  -> name bound: 'stats'      -> True | call: stats.percentage(3,1) = 75.0
from attendance.stats import percentage -> bound: 'percentage' -> True | call: percentage(3,1) = 75.0
in every case the module is loaded ONCE: ['attendance', 'attendance.stats']

=== 2. Naming conflict: two different modules called 'stats' ===
plain 'import stats' picks: OTHER stats: 4  <- ours (c_modules/stats.py) is hidden
with packages both coexist:  attendance.stats -> 75.0 | other.stats -> OTHER stats: 4
